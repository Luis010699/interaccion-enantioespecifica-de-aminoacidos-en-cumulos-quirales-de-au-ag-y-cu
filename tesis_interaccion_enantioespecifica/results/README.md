# Resultados

Este directorio se mantiene vacío en GitHub.

## Motivo
Los outputs completos de FHI-aims y archivos derivados pueden ser demasiado grandes,
ruidosos o poco adecuados para control de versiones.

## Qué sí hacer
- Guardar resultados localmente durante el trabajo diario.
- Publicar datasets o resultados seleccionados en Zenodo, OSF o figshare.
- Enlazar aquí, en el futuro, la ubicación persistente de los datos asociados.

## Qué no subir
- logs masivos
- archivos de reinicio
- densidades electrónicas pesadas
- archivos binarios grandes
